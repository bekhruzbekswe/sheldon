# report-stitcher Specification (delta)

## MODIFIED Requirements

### Requirement: Render report shape with intro, headings, sources

The output Markdown SHALL contain, in order: a `# <task>` H1 title, a single line "Generated by Sheldon on `<ISO date>`. Researched for `<duration>`.", the intro paragraph, a `## <Title-Cased-label>` H2 per section followed by its body, a `## Conclusion` H2 followed by the outro, and a `## Sources` H2 followed by the bibliography list.

Section labels stored in cluster outputs are kebab-case slugs (e.g. `ai-patents-fuel-profit`). The stitcher SHALL render them in human-readable Title Case for H2 headings only — storage, event payloads, and the `topic_tag` column remain kebab-case. Rendering rules:

- Split on `-`.
- Title-case each token (first letter upper, rest lower).
- Replace any token whose lowercase form matches an entry in the per-file `INITIALISMS` constant (`ai`, `bpo`, `rag`, `roi`, `sla`, `api`, `csr`, `bot`, `bott`, `it`, `kpi`, `crm`) with the all-uppercase form.
- Join tokens with a single space.

Examples:

| Stored label | Rendered heading |
|---|---|
| `ai-patents-fuel-profit` | `## AI Patents Fuel Profit` |
| `legacy-bpo-disruption-targets` | `## Legacy BPO Disruption Targets` |
| `enterprise-unstructured-data-challenges` | `## Enterprise Unstructured Data Challenges` |
| `rag-privacy-and-ethics` | `## RAG Privacy And Ethics` |

#### Scenario: Six sections rendered in order with Title-Case headings

- **GIVEN** an input with 6 sections labeled `a-x`, `b-y`, `c-z`, `d-w`, `e-v`, `f-u` (in size-descending order)
- **WHEN** `stitchReport(...)` runs
- **THEN** the output contains exactly 6 H2 section headings in order, with Title-Case-rendered labels
- **AND** also exactly one `## Conclusion` and one `## Sources` H2 each

#### Scenario: Initialism preservation

- **GIVEN** a section with `label = 'ai-patents-fuel-profit'`
- **WHEN** the stitcher renders the H2
- **THEN** the output contains the exact line `## AI Patents Fuel Profit`
- **AND** does NOT contain `## Ai Patents Fuel Profit`

#### Scenario: Storage and event payloads unchanged

- **WHEN** the cluster step emits a `cluster.computed` event with `payload.sizes[].label = 'ai-patents-fuel-profit'`
- **THEN** the event payload contains that kebab-case label, NOT a Title-Cased version
- **AND** the per-section `section.written` event payload's `label` field is also the kebab-case slug
